=====================================================
QUARK(퀀크)를 아이폰 Siri 단축어로 제어하기 — 설정 가이드
=====================================================

[0단계] 토큰 메모해두기
-----------------------
아래 토큰을 메모장이나 비밀번호 관리 앱에 잠깐 저장해두세요.
(단축어 안에 그대로 입력하게 됩니다. 아이폰 분실 시 재발급 필요.)

토큰:
bbaf54948825231f568bda2a247eb8c41effd8c651c0ca1e9f5ebfc4275a1545

전체 헤더 형태 (단축어에 그대로 입력):
Authorization: Bearer bbaf54948825231f568bda2a247eb8c41effd8c651c0ca1e9f5ebfc4275a1545


=====================================================
[A] "퀀크에게 물어보기" 단축어 만들기
   (음성으로 자유롭게 질문/명령 — 일정, 할 일, 조명 제어 등 전부 가능)
=====================================================

1. 단축어 앱 열기 → 우측 상단 + (새 단축어 만들기)

2. 동작 추가 → "텍스트 받아쓰기" 검색 → 추가
   (또는 "입력 요청"으로 텍스트 직접 타이핑 받아도 됨)

3. 동작 추가 → "URL의 콘텐츠 가져오기" 검색 → 추가
   - URL: https://quark.quoding.com/api/siri/ask
   - 메서드: POST
   - 헤더 추가:
       Authorization → Bearer bbaf54948825231f568bda2a247eb8c41effd8c651c0ca1e9f5ebfc4275a1545
       Content-Type  → application/json
   - 요청 본문: JSON 선택
       키: message
       값: 2단계에서 받은 "받아쓰기 텍스트" 변수를 끌어다 넣기

4. 동작 추가 → "사전에서 값 가져오기" (또는 "입력에서 사전 가져오기" → "사전 값 가져오기")
   - 입력: 방금 URL 호출 결과 (자동 연결됨)
   - 가져올 키: reply

5. 동작 추가 → "텍스트 음성 출력 (Speak Text)"
   - 입력: 방금 가져온 reply 값

6. 단축어 이름을 "퀀크"로 짓고 저장

7. 단축어 설정(점 세 개 또는 i 아이콘) → "Siri에 추가"
   → 트리거 문구 녹음 (예: "퀀크한테 물어봐")

✅ 완성: "Hey Siri, 퀀크한테 물어봐" → 말하기 → 퀀크가 음성으로 답변
   (일정 조회/추가, 할 일, 조명·씬·에어컨 제어, 습관·기분·수면 기록 등
    에이전트가 이미 할 수 있는 모든 기능을 음성으로 사용 가능)


=====================================================
[B] 위치/시간 기반 자동화 (선택사항 — 나중에 천천히 추가해도 됨)
=====================================================

설정 → 단축어 앱 → 자동화 탭 → + → 개인 자동화 생성

  트리거            |  동작
  ------------------|--------------------------------------------------------
  위치 도착 (집)     |  POST https://quark.quoding.com/api/devices/cmd
                    |  (헤더는 위 [0단계]와 동일)
                    |  본문: {"device_id":"scene","metric":"apply","value":"home"}
  ------------------|--------------------------------------------------------
  위치 출발 (집)     |  같은 방식, value를 "relax" 등으로
  ------------------|--------------------------------------------------------
  시간 (예: 08:10)  |  "퀀크" 단축어를
                    |  "오늘 일정이랑 할 일 알려줘" 입력으로 실행 (아침 브리핑)
  ------------------|--------------------------------------------------------
  NFC 태그          |  "퀀크" 단축어를 "집중 모드 켜줘"로 실행
                    |  (책상 앞에 NFC 태그 부착)

⚠️ 주의: 자동화를 처음 만들 때는 "실행 전 확인"을 켜둔 채로
   며칠 테스트한 뒤, 오작동이 없는 걸 확인하고 나서
   "확인 없이 실행"으로 전환하는 걸 추천합니다.
   (위치 트리거는 가끔 오탐이 있을 수 있음)
